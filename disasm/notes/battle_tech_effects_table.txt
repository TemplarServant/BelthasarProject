COLUMNS (per tech):
  id name | chars = CC/249F[(CC/1BEB[id*11]+0)&7F * 3] participants (effect k is run AS participant k)
  MP      = participant k pays CC/253B[ CC/1BEB[id*11+5+k] & 7F ]  (C1/CB48/CB61/CB7A)
  grp     = CC/1ACB[id*2] -> $9EE4 -> $960D; handler = C1/1FF8[grp & 7F] (bit7 = PC-side cursor, C1/1F9D)
  shp     = CC/1ACC[id*2] & 3F -> $9EE5 low bits (consumer not traced)
  +0 +1   = record bytes: +0 bit7 magic-learn gate (C1/F482); +1 bit6 -> $AE4D|=20 nomiss, bit5 -> $AE4D|=10 noDE87
            (C1/D593-D5B0 + D629), &7 -> C1/EB68 display sum (C1/D732); +1 bit7 has no long-absolute reader
  elem    = +3 -> $B190 (C1/D6A4); read only by routine 10 C1/EF39: bit7->res +3F, 6->+40, 5->+41, 4->+42
  anim    = CD/45A6[id*7][0] -> $9877 (C1/45AA)
  effK    = CC/213F[+5+k] 12-byte header (C1/D5EF), or SKIP when bit7 (C1/D5D4 -> D71E = next effect, MP only)
            B2CC = CC/1BEB[+8+k] -> CC/2A05[B2CC*3] = (routine,$1C,$1E) through C1/FA61 (C1/EB1C via DCAD's EA6F)
  needs   = mechanism tags (legend below); port = what src/battle.c lacks for this tech's EFFECT (not its pixels)

TAGS: K0 heal D221 | K1 cure/revive D23E | K2 status D267 | K6 charm D3BF | K8 multi-hit D431 | T1/T3/T5/T6 = E0F5
  formula type | HITROLL = C1/DC64 roll (effective $AE4D bit5 clear) | DE87 = header+10 vs enemy +0x19 gate ($AE4D
  bit4 clear) | WPNFX = $AE4E bit7 -> weapon's own CC/2A05 effect (C1/EA7D) | rN = C1/FA61 routine N | Gxx = target
  handler | DBAAcatN = C1/DBAA category N | SKIPCONT = a bit7 effect before a real one | COMBO = >1 damaging
  participant | MENUCOMBO = dual/triple menu listing.
PORTED set used for "core PORTED": T1 T3 T6 G07 G08 G12 r2 r10 r11 COMBO. DE87/WPNFX are listed as gates inert vs
  GATO (+0x19 = 00; Wood Sword +0x47 = 00). Cross-cutting gaps (DCAD tail, E65F, victim order, E575...) are NOT in
  the per-tech tag lists -- see re_techfx.md section 9.
